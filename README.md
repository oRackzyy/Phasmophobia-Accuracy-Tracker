# **Ghost Identification Log**

This fun little app was created to track how often my team correctly identifies the ghost type while playing Phasmophobia.

My buddies and I wanted a way to track how good we actually were at correctly guessing the ghost type, and this turned into a cool, interactive way to do that.

Built using HTML, CSS, and JavaScript, this app features an atmospheric interface inspired by my love of Phasmophobia.

## **Features**

* Ghost Identification Tracking — Record successful and unsuccessful ghost identifications

* Investigation Statistics — Track total investigations, correctly identified ghosts, and incorrect guesses as well

* Accuracy Statistics — Calculates your team's overall accuracy

* Streak Tracking — Records your current streak and keeps track of your highest streak

* EMF Accuracy Meter — A five-level accuracy meter inspired by the EMF reader in Phasmophobia.

* Undo Functionality — Reverse the most recently recorded investigation

* Reset Functionality — Allows you to reset the counter

* Keyboard Shortcuts — Quickly record results without manually clicking buttons

* Automatic Saving — Uses browser local storage to preserve statistics between visits

* Offline Support — Can run locally without an internet connection

## **How to Use**

1. Open the Ghost Identification Log in your web browser

2. Play a round of Phasmophobia

3. After completing the investigation, record whether your team correctly identified the ghost or not

4. View your updated accuracy, EMF level, and current streak

5. Continue tracking your team's performance across investigations

## **Keyboard Shortcuts**

**1** - Record a correct guess

**2** - Record an incorrect guess

**Ctrl + Z** - Undo the previous result

**Ctrl + R** - Reset the counter

*Resetting requires confirmation to prevent accidental data loss*

## **Technologies Used**

* HTML5 — Application structure and interface components

* CSS3 — Visual styling, animations, and responsive layout

* JavaScript — Investigation tracking, calculations, keyboard shortcuts, and local storage

*No external libraries or frameworks are required*
